修复后的新闻链接管理页面CSS选择器数量功能

修复的问题

问题1: 计算属性直接显示在页面上

错误代码:

() => { return tableData.value.filter(item => item.cssSelectorCount && item.cssSelectorCount > 0).length; }

问题: 这个函数直接作为模板表达式使用，没有用 computed 包装

修复方案:

正确代码:

import { computed } from 'vue'; const getWebsitesWithCssCount = computed(() => { return tableData.value.filter(item => item.cssSelectorCount && item.cssSelectorCount > 0).length; });

问题2: 分页列表的记录总数不显示

错误代码:

pagination.total = filteredRecords.length; // 错误：修改了分页总数

问题: 将分页总数改为筛选后的数量，导致分页显示错误

修复方案:

正确代码:

// 保持后端返回的总数，不修改为筛选后的数量 pagination.total = res.total || 0;

代码修改总结

1. 导入 computed

import { ref, reactive, onMounted, watch, computed } from 'vue';

2. 修复计算属性

// 错误：直接使用函数 const getWebsitesWithCssCount = () => { ... }; // 正确：使用 computed const getWebsitesWithCssCount = computed(() => { ... });

3. 修复分页总数

// 错误：修改为筛选后的数量 pagination.total = filteredRecords.length; // 正确：保持后端返回的总数 pagination.total = res.total || 0;

4. 添加筛选提示

// 获取筛选标签 const getFilterLabel = (filterValue) => { const filterMap = { 'no_css': '未配置CSS', 'has_css': '有CSS配置', 'has_enabled': '有启用的CSS', 'all_disabled': '全部禁用' }; return filterMap[filterValue] || filterValue; };

5. 添加空数据提示

<div class="pagination-info"> <span v-if="searchParams.cssFilter && tableData.length === 0"> <el-icon><Warning /></el-icon> 当前筛选条件下无数据，请调整筛选条件 </span> <span v-else-if="searchParams.cssFilter"> 当前显示筛选结果 ({{ tableData.length }} 条) </span> </div>

使用注意事项

1. 计算属性使用

  • 所有需要响应式计算的属性都要用 computed() 包装
  • 在模板中使用时直接引用，不需要加括号：{{ getWebsitesWithCssCount }}
  • 在JavaScript中使用时需要加 .value：getWebsitesWithCssCount.value

2. 分页处理

  • 分页总数应该来自后端API，不要在前端修改
  • 客户端筛选只影响当前页的显示，不影响分页总数
  • 当筛选后当前页无数据时，给出明确提示

3. 筛选功能

  • 筛选条件变化时自动重置到第一页
  • 显示当前筛选状态，让用户知道正在查看筛选结果
  • 提供清除筛选的便捷方式

4. 用户体验

  • 提供明确的状态提示（颜色编码、标签、图标）
  • 添加悬停提示，显示详细信息
  • 支持点击交互，提高操作效率
  • 批量操作功能，提高管理效率
