新闻链接管理页面CSS选择器数量功能演示

1. 表格列显示效果

在新闻链接管理表格中添加了"CSS选择器"列，显示每个网站的CSS选择器配置情况：

网站名称 URL 语言 CSS选择器 创建时间 操作
安全内参 https://www.secrss.com zh 3 2启 1禁 2024-01-01 10:00:00
Example News https://news.example.com en 0 未配置 2024-01-02 11:00:00
Tech Blog https://blog.tech.com en 2 2禁 2024-01-03 12:00:00

颜色说明：

  • 绿色: 有启用的CSS选择器，可以正常抓取新闻
  • 黄色: 有CSS选择器但都禁用了，不会抓取新闻
  • 红色: 没有配置CSS选择器，无法抓取新闻

2. 统计信息显示

在表格上方显示CSS选择器的总体统计信息：

网站总数: 3
已配置CSS: 2
未配置CSS: 1
CSS总数: 5

3. 筛选功能

新增CSS选择器筛选功能：

  • 未配置: 显示没有配置CSS选择器的网站
  • 有配置: 显示有配置CSS选择器的网站
  • 有启用的: 显示有启用CSS选择器的网站
  • 全部禁用: 显示所有CSS选择器都禁用的网站

4. 交互功能

  • 点击CSS选择器数字: 直接跳转到该网站的CSS选择器管理页面
  • CSS选择器按钮: 显示配置数量，未配置时显示红色警告
  • 批量查看未配置CSS: 一键查看所有未配置CSS选择器的网站
  • 排序功能: 支持按CSS选择器数量排序

5. 后端接口变更

新增接口：

POST /api/manager/news-links/page-with-css-count { "page": 1, "size": 10, "keyword": "example", "langs": ["en", "zh"] }

响应新增字段：

{ "cssSelectorCount": 3, "enabledCssSelectorCount": 2, "disabledCssSelectorCount": 1 }

6. 前端代码主要修改

  1. 在API文件中添加新接口调用
  2. 修改表格列，添加CSS选择器显示
  3. 添加统计信息显示
  4. 添加筛选功能
  5. 添加交互功能（点击跳转、批量操作等）
  6. 添加样式美化

7. 使用效果

通过这次修改，新闻链接管理页面实现了以下改进：

  • 可视化: 直观显示每个网站的CSS选择器配置状态
  • 效率提升: 无需跳转详情页即可了解配置情况
  • 问题识别: 快速识别未配置或配置有问题的网站
  • 批量管理: 支持批量查看和操作
  • 数据统计: 提供整体配置情况统计
